# ILI9488 / XPT2046 Hardware Record

Status: signal topology, VCC, and backlight control confirmed for bench wiring.

## Controller board

```text
Board family: ESP32-S3 DevKitC-1-style 44-pin clone
Module marking: S3-N16R8
Flash: 16 MB
PSRAM: 8 MB
USB: two USB-C connectors
Buttons: RST and BOOT
Onboard RGB LED: likely GPIO48
```

Observed connector behavior on this clone:

- The connector labeled `USB` powers the board and enumerates the ESP32-S3
  native USB serial device. Use it for this bench.
- The connector labeled `COM` neither powers the board nor produces a local
  Windows device-enumeration event, even when the board is externally powered.
  Treat that connector/bridge as unavailable unless it is repaired separately.
- Firmware enables Arduino USB CDC on boot so `Serial` heartbeat output appears
  on the working native USB connection rather than UART0.

Pins deliberately avoided for this bench:

- GPIO0, GPIO45, and GPIO46: boot-strapping pins.
- GPIO19 and GPIO20: native USB D- and D+.
- GPIO43 and GPIO44: UART diagnostics.
- GPIO48: onboard addressable RGB LED.

## Display module

```text
PCB revision: V1.0
Seller identification: ILI9488
Panel interface: SPI
Touch controller: XPT2046, visibly marked U2
Touch type: resistive
Main header: 14 pins
SD interface: separate unpopulated four-pad SPI header
```

The LCD controller itself is concealed by the display assembly, so the first
bring-up must still confirm expected ILI9488 initialization, dimensions, color
order, and inversion behavior.

## Main header

Silkscreen order from the `T_IRQ` end toward the `VCC` end:

| Pin | Label | Function |
|---:|---|---|
| 1 | T_IRQ | Touch interrupt |
| 2 | T_DO | Touch MISO |
| 3 | T_DIN | Touch MOSI |
| 4 | T_CS | Touch chip select |
| 5 | T_CLK | Touch clock |
| 6 | SDO(MISO) | LCD MISO |
| 7 | LED | Active-high 3.3 V logic/PWM backlight control |
| 8 | SCK | LCD clock |
| 9 | SDI(MOSI) | LCD MOSI |
| 10 | DC/RS | LCD data/command |
| 11 | RESET | LCD reset |
| 12 | CS | LCD chip select |
| 13 | GND | Ground |
| 14 | VCC | 5 V module supply with J1 open |

## Accepted signal pin assignment

```cpp
// Shared SPI bus.
constexpr int kSpiSclk = 12;
constexpr int kSpiMosi = 11;
constexpr int kSpiMiso = 13;

// LCD.
constexpr int kLcdCs = 10;
constexpr int kLcdDc = 9;
constexpr int kLcdReset = 14;

// XPT2046.
constexpr int kTouchCs = 8;
constexpr int kTouchIrq = 7;

// Active-high logic/PWM control for the onboard transistor stage.
constexpr int kBacklightControl = 6;
```

## Signal wiring

| ESP32-S3 | Display module |
|---|---|
| GPIO12 | SCK and T_CLK |
| GPIO11 | SDI(MOSI) and T_DIN |
| GPIO13 | T_DO |
| GPIO10 | CS |
| GPIO9 | DC/RS |
| GPIO14 | RESET |
| GPIO8 | T_CS |
| GPIO7 | T_IRQ |
| GPIO6 | LED |
| Verified board 5V | VCC |
| GND | GND |

LCD and touch share SCLK and MOSI. Touch provides MISO. LCD and touch retain
separate chip selects and the driver must use bus locking.

## Intentionally disconnected

- LCD `SDO(MISO)` during initial write-only display bring-up.
- `SD_CS`, `SD_MOSI`, `SD_MISO`, and `SD_SCK`.

## Power and backlight resolution

Hosyond directs this module to the LCDWiki MSP3520 documentation, and the PCB
matches its XC6206 regulator, J1 selector, and S8050 backlight transistor stage.

- J1 is physically open, selecting external 5 V input through the onboard 3.3 V
  regulator. Leave J1 open and unmodified.
- Connect module VCC to the development board header marked `5V` only after
  measuring that header at approximately 5 V relative to GND while powered
  through the USB connector that will be used.
- All LCD and touch logic remains 3.3 V.
- `LED` drives the onboard S8050 transistor through a 1 kOhm base resistor. It
  is an active-high logic/PWM input, not the raw backlight-current path.
- Connect GPIO6 directly to `LED`. Drive it LOW before display initialization,
  then HIGH or PWM after initialization. Do not connect `LED` to 5 V.

## Bring-up orientation

The N203 logical display is 480 x 320 landscape. Start with LovyanGFX rotation
1; use rotation 3 if the physical connector/bezel orientation requires the
opposite landscape direction. Record the final rotation together with touch
axis swap/inversion during calibration.

## SD interface

The microSD slot routes to a separate four-pad header:

```text
SD_CS
SD_MOSI
SD_MISO
SD_SCK
```

The SD interface is outside the display-bench scope and will remain unwired.
